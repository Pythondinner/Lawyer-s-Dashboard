## 二、体系建设建议

排序：先按法律生效日期（客观事实，代码计算），同一生效日期下再按业务优先级P0/P1/P2。

### Art.9 风险管理体系

- **缺失点**: 尚未建立覆盖AI系统全生命周期的正式风险管理体系，仅可能存在非正式风险评估。
- **建设建议**: 建立文件化的风险管理系统，定义风险识别、评估、缓解的持续迭代流程，覆盖运行、监测、反馈和退役阶段。制定风险接受标准和残余风险报告。
- **法条依据**: Art.9(2)
- **业务优先级**: P0
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）

### Art.16 提供者义务

- **缺失点**: 缺乏系统性合规管理，未能全面履行提供者义务，如合格评定程序、文件保存和市场监管对接。
- **建设建议**: 任命合规负责人，制定提供者义务清单，确保完成合格评定程序、签署符合性声明、加贴CE标志，并建立与主管当局的沟通机制。
- **法条依据**: Art.16(f)
- **业务优先级**: P0
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）

### Art.17 质量管理体系

- **缺失点**: 尚未建立制度化的质量管理体系，缺少书面政策、程序和指令来覆盖法规要求的质量要素。
- **建设建议**: 建立质量管理体系，至少包括风险管理程序、数据管理程序、上市后监测程序、事件报告程序、设计控制程序及文档控制程序，形成手册并贯彻实施。
- **法条依据**: Art.17(1)
- **业务优先级**: P0
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）

### Art.10 数据与数据治理

- **缺失点**: 尚未制定针对训练、验证、测试数据集的数据治理和质量标准政策，缺少数据溯源、偏见检测和纠正机制。
- **建设建议**: 建立数据治理政策，记录数据来源、标注过程和偏差检测方法；确保训练数据集具有代表性、完整且无偏见，并执行数据质量评估。
- **法条依据**: Art.10(2)
- **业务优先级**: P1
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）

### Art.11 技术文档

- **缺失点**: 系统投放市场前未编制符合法规要求的技术文档，缺少系统设计、算法说明及合规论证。
- **建设建议**: 编制技术文档，涵盖系统架构、开发方法、预期用途、符合性评估等，并在上市前提交。建立文档更新流程以保持持续符合。
- **法条依据**: Art.11(1)
- **业务优先级**: P1
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）

### Art.12 记录保存

- **缺失点**: 系统尚不具备自动记录日志功能，无法保证运行生命周期内事件的可追溯性。
- **建设建议**: 在系统中内置日志功能，自动记录每次交互的关键事件（如输入、输出、错误、人工干预等），确保日志可访问且不可篡改，用于监测和审计。
- **法条依据**: Art.12(1)
- **业务优先级**: P1
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）

### Art.14 人工监督

- **缺失点**: 缺少人机界面工具和流程使人类监督者能够有效理解和干预系统决策，难以识别自动化偏见或推翻错误输出。
- **建设建议**: 设计监督界面，提供系统置信度、解释信息，并设置“人工复核”、“最终决定”等机制，培训监督人员认识系统局限和偏见。编制监督操作规程。
- **法条依据**: Art.14(2)
- **业务优先级**: P1
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）

### Art.15 准确性、稳健性与网络安全

- **缺失点**: 未对系统准确性、稳健性进行系统测试和验证，也未建立应对网络攻击和输入异常的保障措施。
- **建设建议**: 实施全面的准确性测试和鲁棒性验证，包括对抗性攻击、边缘案例和噪声输入。建立网络安全保护机制，如数据加密、访问控制、漏洞管理，并在生命周期内持续监控。
- **法条依据**: Art.15(1)
- **业务优先级**: P1
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）

### Art.13 透明度与信息提供

- **缺失点**: 未提供足够的使用说明和解释资料，部署者难以理解系统能力、局限和正确解释输出。
- **建设建议**: 编制详细使用说明，包括系统预期目的、性能指标、限制条件、典型误用案例以及如何解读系统输出。确保界面能提示用户其为AI系统。
- **法条依据**: Art.13(1)
- **业务优先级**: P2
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）

### Art.18 文件保存

- **缺失点**: 未明确技术文件和质量管理体系文件的长期保存政策，无法保证10年内可提供给监管机构。
- **建设建议**: 制定文件保存政策，确保技术文档、质量管理体系文件及其他相关记录自投放市场起保存至少10年，并建立档案管理和检索机制。
- **法条依据**: Art.18(1)
- **业务优先级**: P2
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）

### Art.19 自动生成日志

- **缺失点**: 系统未生成日志文件，或现有日志未按保存期限要求进行管理。
- **建设建议**: 确保高风险AI系统自动生成日志，并保存至少6个月。制定日志管理规程，明确日志格式、存储位置、访问权限和备份策略。
- **法条依据**: Art.19
- **业务优先级**: P2
- **法律生效状态**: 已生效（自 2026-08-02 起已生效）
